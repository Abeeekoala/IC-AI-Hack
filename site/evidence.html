The Bexsero test scored 0 of 3

On the stored 40-protein subset, with real Vaxign-ML scores, the top three are an IgA protease, the TonB-dependent receptor NMB1829 and the hemoglobin receptor HmbR. The three Bexsero antigens land at NadA 7th, NHBA 9th and fHbp 14th of 40.

Top three by score The three Bexsero antigens Every other protein

Why the miss does not settle anything

  • It is 40 proteins, a stored subset of 2,003.
  • The stock Vaxign-ML model was trained on all of Protegen, which contains these antigens, so retrieving them is circular.
  • The leakage assertion reads not checked, and VaxForge raises a leakage-risk warning with holdout_enforced: false.
  • In the real-tools run the three antigens survive S4 only because allergenicity and conservancy were set to flag instead of reject, after an earlier strict run rejected all three. The recall@3 result reads the S3 ranking only.

Three possible outcomes of the leakage check

not checked
No reference ID set was supplied. The report says so and shows no pass.
ok
No ranked protein or listed homologue is in the training set. Meaningful only when both use one ID namespace.
violated
A protein is in the training set. The report is written without any recall figure, and the command exits with status 2.

Leakage is common. Say it first.

Vaxign-ML is trained on Protegen, so rediscovering Bexsero’s antigens with it proves little. The fix is to remove N. meningitidis from the training set before the Tier 2 run, which is what leave-one-pathogen-out does, and to state it.

The failure is widespread, not hypothetical: DeepSol and SKADE were found to have 75.1% overlap between training and test sets, and a 2025 paper in this subfield reports no held-out test set, no AUC and no cross-validation at all.

Not done yet

A model trained on a leakage-audited split, reported next to the stock one, is the first item on the roadmap. Until then the Bexsero figure is shown only with this warning, and it is never described as validation or as refutation.

What we chose not to build

Listing what was refused is itself a result.

  • Phase 1, 2 or 3 trial simulation. No scientific or regulatory basis for vaccines. ICH M15 does not mention vaccines, and the FDA’s paired-meeting programme excludes simulation as a substitute for confirmatory trials.
  • C-ImmSim immune simulation. Only partially described in the literature, with no complete manual and a binary-only derivative, so third parties cannot test it.
  • MD and MM-PBSA “validation”. Computational validation that does not demonstrate immunological efficacy.
  • ClusPro–TLR docking and predicted assay readouts. A prediction is a hypothesis. A measurement is an observation.

Scope and responsible use

VaxForge is restricted to protective-antigen identification and therapeutic binder design. It does not support, and will not be extended to support, work that increases pathogen virulence, transmissibility or immune escape.

Sequence screening before synthesis is a node in the pipeline (S12), not an afterthought.

Recorded model test

Recorded model test, 14 November

One reviewed fHbp protocol was compiled into 13 OT-2 sessions by two Claude models, Sonnet 5.5 and Haiku 5.5, with one attempt per model and session. Each program was graded by lint, the Opentrons 7.5.0 simulator and five physical rules, and a refusal is an outcome, not a crash.

PASS
The program passed lint, ran in the simulator and broke none of the five rules.
FAIL
The model wrote a program, and it failed lint, the simulator or a rule check.
REFUSED
The model declined to write code, so there is no program to check.

Select any cell to see the recorded call behind it: what happened, its checks, its raw log and its digest.

A record, not a benchmark. Each model made one attempt per task, so these are recorded outcomes. The 95% Wilson intervals in the test report are wide: Sonnet 13 of 13 gives 0.77 to 1.00, and Haiku 4 of 13 gives 0.13 to 0.58. Sonnet’s passes do not say the protocols are right for an experiment. A PASS means the code ran and broke none of the checked rules.
