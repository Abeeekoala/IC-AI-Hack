# demo_data/s3_s7_real: stream B (S3 to S7), real-tool outputs

Stream B's real-tool data, for whoever builds the UI. Nothing here is regenerated by `make demo-offline`; `demo-offline` reads two of these files.

## What is here

| File | What it is | How it was made | Real / stand-in |
|---|---|---|---|
| `vaxign_ml_scores.nmb_fixture.tsv` + `.meta.json` | Vaxign-ML protegenicity for the 40 fixture proteins | Docker image `e4ong1031/vaxign-ml` (digest in the meta file), Gram-negative mode, CPU, Apple-silicon Mac, 2026-11-14, through S3's `VaxignMLBackend` | **Real tool output.** The stock model was trained on all of Protegen, so the Bexsero antigens were in its training set (`holdout_enforced: false`) |
| `s7_structure.real_mc58_boltz_cpu.json` | A trimmed real S7 payload | Boltz-2 2.2.1 on CPU with `msa: empty` (no sequence left the machine), DiscoTope-3.0 on the Boltz models; made 2026-11-14, S7 re-run 2026-11-15 | **Real, but a sample** of *N. meningitidis* MC58 proteins, not the 40 fixture proteins and not a full S7. Read its `_about` first |

**The complete S3 to S12 real-tool run is not copied here.** It is on main as [`results/nmb_real_run/`](../../results/nmb_real_run/) (PR #97): artifacts S0 to S12, `report.html`, `SUMMARY.md` and the exact command. Read the artifacts there rather than a copy.

## The tools behind `results/nmb_real_run/` (2026-11-15, the 40-protein fixture, offline, Apple-silicon Mac)

BLAST+ 2.17.0 (human homology, conservancy), AlgPred2 1.4 (model 1), ToxinPred2 1.1 (model 1), MHCflurry 2.3.28 (class I, an open-source **alternative** to NetMHCpan), BepiPred-3.0 (linear B-cell). S3 used the real Vaxign-ML scores above through `s3.backend: scores_file`.

## Not run (each artifact lists it under `payload.degraded`)

NetMHCpan and NetMHCIIpan (DTU licence), DiscoTope-3.0 in that run, Boltz-2 in that run, ESMFold and AF2-no-MSA validators. S2 localisation of the fixture is a UniProt-text stand-in, not PSORTb.

## Whose number is whose

- **Tool's own:** the protegenicity percentile (Vaxign-ML), MHCflurry presentation percentiles, BepiPred scores, AlgPred2 and ToxinPred2 scores, Boltz pLDDT.
- **Ours (derived):** S3 composite and rank, S4 survive/flag/reject, S5 epitope scores, S6 population coverage (our implementation of the IEDB method; the run exports an epitope-allele file to cross-check in the official tool), S7 final order, the S4 reject-versus-flag setting.
- **S4 is tuned:** fHbp, NadA and NHBA survive S4 because allergenicity and conservancy were set to flag after an earlier strict run rejected them. Say that wherever the three antigens are shown. Bexsero recall@3 reads the S3 ranking only and stays 0 of 3 (fHbp 14th, NadA 7th, NHBA 9th); it is circular.

## Not verified

No wet-lab result exists for any candidate. The leave-one-pathogen-out test with a retrained model has not been run. The fixture is 40 of 2,003 proteins and was built to contain the Bexsero antigens. The Boltz sample was not re-run after the 2026-11-15 S7 re-run beyond what its `_about` says. Sizes: all files here are under 25 KB; no model weights are stored (Vaxign-ML is a 4.9 GB image, Boltz-2 weights are 7.6 GB; both are re-pulled by `docs/TOOLS_SETUP.md`).
